# 🛒 Full Stack E-Commerce Platform

A production-grade full stack e-commerce application built with **React, Node.js, Express, and MongoDB**, focusing on real-world business workflows, security, and scalability.

---

## 🚀 Features

### 🔐 Authentication & Security
- JWT-based authentication
- Role-based access control (Admin / User)
- Email verification
- Forgot & reset password
- Rate limiting
- Validation layer
- Environment-based configuration
- Soft delete for critical resources
- OAuth authentication (Google login)
- JWT-based authentication for protected routes
- OAuth & JWT accounts unified under a single user profile

### 🛍️ Products & Catalog
- Product pagination
- Categories, search & advanced filtering
- Product image upload using **Cloudinary & Multer**
- Stock management
- Wishlist functionality
- Reviews & ratings

### 🛒 Cart, Orders & Payments
- Shopping cart stored in **LocalStorage & Database**
- Cart merge on login (guest → authenticated user)
- Order placement & order history
- Order status tracking
- Coupon & discount system
- **Stripe checkout integration**
- Stripe refunds
- Cash order cancellation

### 🛠️ Admin Dashboard
- Admin dashboard interface
- Add / edit / delete products
- View and manage orders

### ⚙️ UX & Architecture
- RESTful API design
- API documentation
- Reusable frontend components
- State management
- Loading states & centralized error handling
- Fully responsive UI

---

## 🧰 Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Payments:** Stripe
- **Media Storage:** Cloudinary
- **Deployment:** Vercel (Frontend)
